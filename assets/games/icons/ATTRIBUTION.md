# Twemoji game icons

The SVG files in this directory are from Twemoji 17.0.3:

- Project: https://github.com/jdecked/twemoji
- Asset source: `assets/svg` from release 17.0.3
- Graphics license: CC-BY 4.0
- Code license: MIT

The files are bundled with the application so food icons render identically on
every device instead of using the device's emoji font.
